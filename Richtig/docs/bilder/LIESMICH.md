# Bilder

`overlay.png` bindet die README ein und wird zusätzlich als Vorschaubild des
Repositorys gebraucht (1280 × 640 px).

Was darauf zu sehen sein sollte: das Overlay im Betrieb – links das mitlaufende
Gespräch mit deutscher Übersetzung, rechts eine Antwortkarte. Solange die Datei
fehlt, zeigt GitHub an der Stelle nichts an; der übrige Text bleibt heil.
